# Student Journey Intelligence Engine

An end-to-end machine learning system that predicts whether a student is likely to
**continue enrollment in the next academic term**, explains the main contributing
factors, identifies academic bottlenecks, and exposes predictions through an API and
a dashboard.

> **This is a portfolio / educational project.** It is not affiliated with, endorsed
> by, or in use at any real university. It does not use real student data. See
> [Data](#data) and [Responsible use](#responsible-use) below.

## Problem

Academic advisors want an early signal for which students may not re-enroll next term,
so they can prioritize outreach and support — **not** to automate decisions about
students. This system predicts `persisted_next_term` (did the student enroll in the
immediately following term) from academic and enrollment history, and explains *why*
the model thinks so.

## Data

Two data sources are used, both non-identifying:

1. **Synthetic multi-term student data** (primary) — generated by
   [`src/student_journey/data/generate_synthetic_data.py`](src/student_journey/data/generate_synthetic_data.py).
   Every field is fabricated; no real student, institution, or record is represented.
   See [`data/DATA_DICTIONARY.md`](data/DATA_DICTIONARY.md) for the schema.
2. **UCI "Predict Students' Dropout and Academic Success" dataset** (secondary,
   benchmark only) — a real, already-anonymized public dataset used in Phase 3 to
   sanity-check that the modeling approach transfers to a different data source. It is
   not used for the primary training pipeline described above.

## Architecture

See [`docs/architecture.md`](docs/architecture.md) for the full diagram. In short:
synthetic/public data → SQLite → SQL validation/transform → pandas feature engineering
→ scikit-learn/XGBoost models tracked in MLflow → FastAPI serving layer with SHAP
explanations → Streamlit dashboard.

## Setup

Requires Python 3.9+.

```bash
git clone <repo-url>
cd student-journey-intelligence-engine
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Phase-by-phase run instructions are added below as each phase is completed.

### Phase 2: generate data, load into SQLite, validate, build features

```bash
export PYTHONPATH=src   # or `pip install -e .`

python -m student_journey.data.generate_synthetic_data   # writes data/raw/*.csv
python -m student_journey.data.ingest                    # loads CSVs into db/student_journey.db
python -m student_journey.data.validate                  # runs 12 SQL data-quality/leakage checks; exits non-zero on failure
python -m student_journey.features.build_features         # writes the `features` table + data/processed/features.parquet

pytest tests/test_data_validation.py tests/test_features.py -v
```

All 12 validation checks and 11 tests pass as of this commit (verified by running the above).

## Responsible use

- This system identifies **statistical patterns** in historical-style data. It does
  not determine, guarantee, or explain any individual student's actual future.
- Intended use: decision **support** for advisors (e.g., prioritizing outreach).
  Non-intended use: automated decisions about admissions, financial aid, discipline,
  or academic standing.
- No real student PII is collected, stored, or processed by this project.
- See [`docs/model_card.md`](docs/model_card.md) *(added in Phase 4)* for full
  intended use, limitations, and fairness considerations.
